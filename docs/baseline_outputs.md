# Historical baseline outputs

The earlier contents of this file were raw responses from a prior
database-systems corpus and an older implementation. They are archived only as
an example of why source review matters; they are not representative current
TrustLens outputs and should not be used in a demo, an interview, or an
evaluation claim.

For current evidence, use a versioned workspace source set and follow
[evaluation.md](evaluation.md). Preserve the exact answer contracts, their
linked evidence, provider configuration, and human-review labels with any
future benchmark report.
